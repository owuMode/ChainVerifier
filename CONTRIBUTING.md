# Contributing to ChainVerifier

First off — thanks for considering contributing to ChainVerifier!

## How Can I Contribute?

###  Reporting Bugs

Open an [issue](https://github.com/owuMode/ChainVerifier/issues) with:

- **Clear title** describing the problem
- **Steps to reproduce** the issue
- **Expected behavior** vs **actual behavior**
- **Screenshots** (if applicable)
- **System info:**
  - Windows version
  - ChainVerifier version
  - Whether you're running as Administrator

###  Suggesting Features

Open an [issue](https://github.com/owuMode/ChainVerifier/issues) with:

- **Clear title** describing the feature
- **Use case** — why do you need this?
- **Proposed solution** (if you have one)

###  Pull Requests

We welcome PRs! For major changes, please open an issue first to discuss.

**Before submitting:**

1. Follow the existing code style.
2. Test your changes thoroughly.
3. Update documentation if needed.
4. Keep commits clean and descriptive.
