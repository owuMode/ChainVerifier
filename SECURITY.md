# Security Policy

## Supported Versions

| Version | Supported          |
|---------|-------------------|
| 2.9.x   |  Current         |
| 2.0.x   |  Critical only   |
| 1.0.x   |  Not supported   |

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** open a public issue.

Instead, contact:

- **Telegram:** [t.me/owumode_chat](https://t.me/owumode_chat)
- **Website:** [owumode.store](https://owumode.store)

Include:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fixes

We aim to respond within **48 hours**.

## Scope

This project is a memory-editing tool. Known "issues" that are NOT vulnerabilities:

- Antivirus false positives
- SmartScreen warnings
- Anti-cheat blocking access
- Warnings from Windows Defender

These are expected behaviors for this type of software.
